# Бот регистрации на рейд

Discord-бот на Python (`discord.py`) для еженедельных рейдов и коллекционной гачи: публичный эмбед, пошаговая регистрация, автоматические счётчики мест, скамья запасных, напоминания, локальная валюта и пул наград.

## Что реализовано

- Кнопка **«Участвовать»** под публичным эмбедом — страница 1.
- Пошаговая регистрация в личных (ephemeral) сообщениях:
  1. выбор роли: **Танк / Хил / ДД**;
  2. выбор одной или двух специализаций с иконками (у танка и хила сейчас по одной);
  3. выбор статуса: **Присоединиться / Скамья запасных / Буду отсутствовать**.
- Если в основном составе выбранной роли нет свободных мест, «Присоединиться» автоматически записывает человека в **скамью запасных**.
- Публичный эмбед обновляется после каждой записи. В заголовках отображаются счётчики: `Танк: (1/1)`, `Хил: (0/2)`, `ДД: (4/7)`.
- Иконки выбранных специализаций выводятся рядом с ником в эмбеде — до двух иконок на участника.
- Иконки ролей и специализаций зафиксированы как **application emoji** бота — загружать их заново не нужно.
- Название, лимиты и часовой пояс сохраняются между запусками. Их можно менять в `/настройки`. После обновления бота старые лимиты `2/3/8` один раз автоматически заменяются на `1/2/7`.
- Перед публичным эмбедом бот упоминает роль `1482725169884565627`.
- Дата выбирается в календаре, описание рейда в команде не запрашивается.
- Рейдовый эмбед и его напоминание участникам работают отдельно от активностей.
- Можно настроить отдельные напоминания об активностях — ежедневные или еженедельные, с несколькими расписаниями.
- Напоминание об активности приходит за 15 минут до начала в выбранный канал, с настраиваемой ролью и описанием.
- Сообщения активностей автоматически удаляются через заданное время.
- За 15 минут до начала рейда бот по-прежнему упоминает только **основной состав** и **скамью запасных** рейда. Отсутствующие не упоминаются.
- Время выводится через Discord timestamps, поэтому каждый пользователь видит его в своём локальном часовом поясе.
- Регистрации сохраняются в JSON и не пропадают после перезапуска.
- **`/гача`** — коллекционная гача с локальной валютой **«Осколки гармонии»**, пулом наград, редкостями, гарантией и инвентарём.
- Валюта начисляется за рейды и активности: основной состав и скамья получают награду после начала рейда, а участники активности — за кнопку **«Я участвую»** под напоминанием.
- В `/настройки` можно добавлять предметы в пул, менять их названия, редкость, описание, вес, картинку и публичный анонс.
- За 50, 80 и 150 круток бот гарантированно выдаёт роли **«Лудик»**, **«Гигача»** и **«Лудик король»**.
- При получении **«Ядра гармонии»** бот публикует красивое оповещение в канале, где использовали `/гача`, с иконкой легендарной награды.

## Команды

| Команда | Назначение |
|---|---|
| `/создать` | Открыть календарь и создать рейд |
| `/настройки` | Открыть настройки рейда, активностей и гачи (только с правом «Управлять сервером») |
| `/гача` | Открыть гачу, посмотреть баланс и инвентарь |

- `/создать` требует права **«Управлять сервером»**.
- `/настройки` видна только участникам с правом **«Управлять сервером»** и выполняется владельцем сервера или участниками с ролями:
  - `1482718872959455283`
  - `1565328621286199356`
  - `1482721002894131330`
  - `1482722108428779620`
- `/гача` доступна всем участникам сервера.

  - Весенний зонт, Веер чернильницы
  - Перчатки небесной воли, Веревочный дротик небесной хватки
  - Стратегический меч, Копьё небесного грома
  - Клинок губителя фаланги, Клинок рассекающий снег
  - Адские парные клинки, Смертельный канатный дротик
  - Поясной барабан муз, Поклонник ивового изгиба

На шаге выбора для ДД можно отметить одну или две специализации. У танка и хила в каталоге доступно по одной, поэтому они выбирают одну.

При необходимости список и emoji можно изменить в файле, после чего перезапустить бота.

## Быстрый запуск

Требуется Python 3.10+.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
python bot.py
```

Или на Windows просто запустите `run.bat`.

Если проект уже был установлен раньше, после обновления кода обновите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

В `requirements.txt` зафиксирован `discord.py==2.7.1`.

В `.env` нужно указать:

```env
DISCORD_TOKEN=токен_бота
GUILD_ID=ID_сервера
```

`GUILD_ID` необязателен, но с ним слеш-команды появляются сразу. Без него команды синхронизируются глобально и могут появиться с задержкой.

### Создание приложения в Discord

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**.
2. Вкладка **Bot** → **Reset Token** → скопируйте токен в `.env`.
3. Privileged intents не нужны.
4. **OAuth2 → URL Generator**: scopes `bot` и `applications.commands`.
5. Права бота: **View Channels**, **Send Messages**, **Embed Links**, **Attach Files**, **Read Message History**, **Manage Roles**, **Mention @everyone, @here and All Roles** (для упоминания роли рейда).
6. Готовое число разрешений для OAuth2-ссылки: **`268684288`**. Если нужны ветки, добавьте **Send Messages in Threads** и используйте **`275146591232`**.
7. **Attach Files** обязательно для картинок предметов гачи: бот отправляет их как вложения в эмбедах.
8. **Manage Roles** нужен для гарантированных ролей «Лудик», «Гигача» и «Лудик король». Роль бота должна стоять выше этих ролей.
9. Пригласите бота на сервер по ссылке.
10. У пользователя, который настраивает бота, должно быть право **«Управлять сервером»**.

## Настройка и создание рейда

Все настройки находятся в одной команде:

```text
/настройки
```

Команда открывает **личный (ephemeral) эмбед** со всеми настройками:

- название рейдового эмбеда;
- лимиты танков, хилов и ДД;
- часовой пояс;
- все активности: расписание, канал, роль, описание, автоудаление и статус;
- пул гачи: количество предметов и легендарных наград.

Управление:

- **«Настройки рейда»** — изменить название, лимиты и часовой пояс;
- выбрать активность в меню — открыть её настройки;
- **«Добавить активность»** — создать новую;
- **«Настройки гачи»** — открыть управление пулом наград и начислением валюты;
- в настройках активности доступны кнопки для изменения описания, расписания, канала, роли и времени автоудаления.

В **«Настройки гачи»** → **«Начислить валюту»** администратор выбирает пользователя и сумму. За одну операцию можно начислить от 1 до 1 000 000 осколков. Баланс сразу отображается в `/гача`.

Создать рейд можно отдельной командой в нужном канале:

```text
/создать время:20:30
```

- Команда открывает календарь в личном сообщении. Переключайте месяцы стрелками и выберите дату в меню.
- Заголовок и лимиты берутся из `/настройки`.
- Новые лимиты применяются к новым рейдам. Уже созданный эмбед сохраняет лимиты, с которыми был создан.
- Время: `ЧЧ:ММ`.
- Часовой пояс из `/настройки` влияет только на ввод времени и отображение календаря администратором. Участники видят дату и время локально.
- Перед эмбедом публикуется упоминание роли `1482725169884565627`. Роль должна быть доступна для упоминания, а у бота должно быть право **«Mention @everyone, @here and All Roles»**.
- После выбора даты бот публикует эмбед и кнопку «Участвовать».
- Напоминание об участии в рейде уйдёт в этот же канал за 15 минут до начала, если бот в сети.

## Как проходит регистрация

1. Пользователь нажимает **«Участвовать»** под эмбедом.
2. Бот открывает личное сообщение с выбором роли.
3. После выбора роли открывается выбор одной или двух специализаций (у танка и хила сейчас по одной).
4. После выбора специализаций — выбор статуса.
5. Публичный эмбед сразу обновляется: счётчики, ники, иконки, скамья и отсутствующие.

При повторном нажатии «Участвовать» (или «Изменить запись») текущая запись сразу удаляется, а выбор начинается с чистого листа: роль → специализации → статус. Новая запись добавляется только после подтверждения на последнем шаге. Если закрыть окно, не завершив новую регистрацию, старой записи уже не будет. При заполненном основном составе кнопка «Присоединиться» сохранит человека в скамье запасных.

## Активности

Активности — это независимые напоминания, не связанные с рейдовым эмбедом и его участниками. У каждой активности свои канал, роль, описание, время автоудаления и одно или несколько расписаний.

В проект уже добавлены:

- **Вечеринка** — ежедневно, 21:00–21:30;
- **Разгром армии (Босс)** — вторник 20:00–22:00, суббота 19:00–21:00;
- **PvP Арена** — четверг 19:30–21:30, воскресенье 18:30–20:30;
- **Война гильдий** — суббота 21:30–00:00, воскресенье 21:30–00:00.

У новых активностей не заданы канал и роль, поэтому они не отправляются, пока их не настроить.

### Настройка

Откройте `/настройки` и выберите активность в меню под эмбедом.

В карточке активности:

- **«Описание»** — текст, который будет в напоминании;
- **«Расписание»** — дни, время начала и окончания;
- **«Канал»** — куда отправлять напоминание;
- **«Роль»** — кого упомянуть перед сообщением;
- **«Автоудаление»** — через сколько минут удалить сообщение;
- **«Назад»** — возврат к общей панели.

Формат расписания: `День ЧЧ:ММ-ЧЧ:ММ`, несколько расписаний разделяются `;`. Для ежедневного используйте `Ежедневно 21:00-21:30`. Кнопка **«Добавить активность»** создаёт новую активность.

- Время указывается в часовом поясе из раздела **«Настройки рейда»**.
- Напоминание отправляется за 15 минут до начала каждой активности.
- В начале сообщения ставится выбранная роль.
- Сообщение автоматически удаляется через заданное число минут.
- Рейдовые напоминания участникам работают независимо и не отключаются настройкой активностей.

Чтобы активировать четыре готовые активности, откройте каждую в `/настройки` и задайте ей канал и роль.

## Гача и осколки гармонии

Команда:

```text
/гача
```

Открывает личную панель с балансом, количеством круток, прогрессом до гарантии, кнопками крутки и инвентарём.

### Валюта

Локальная валюта — **«Осколки гармонии»** (`✨`). Она хранится отдельно для каждого сервера и пользователя.

Начисления:

- **Рейд:** `+50` основному составу и `+15` скамье запасных. Награда начисляется один раз после времени начала рейда.
- **Активность:** `+25` за кнопку **«Я участвую»** под напоминанием. Награда начисляется один раз за конкретное событие.
- Старые рейды, созданные до обновления, задним числом не награждаются.

### Крутки

- Одна крутка — **100** осколков.
- Десять круток — **900** осколков.
- Гарантия: легендарная награда не реже чем раз в **80** круток.
- Базовый шанс **«Ядра гармонии»** — **0,1%** (без учёта гарантии).
- Каждый предмет имеет редкость и вес. Вес влияет на шанс внутри своей редкости.
- Дубликаты не пропадают: в инвентаре показывается количество копий.

### Пул наград

В проект добавлен пул из **35 предметов**: 7 обычных, 4 необычных, 3 редких, 12 эпических и 9 легендарных. Главная легендарная награда — **«Ядро гармонии»** с шансом **0,1%**. Её иконка лежит в `assets/gacha/core-of-harmony.png`.

«Руда гармонии» — отдельный обычный серый предмет, не связанный с «Ядром гармонии».

Редкости соответствуют цветовой индикации картинок: серый — обычная, зелёный — необычная, синий — редкая, фиолетовый — эпическая, золотисто-коричневый — легендарная.

Управление пулом в `/настройки` → **«Настройки гачи»**:

- **«Добавить предмет»** — название, редкость, описание и вес;
- **«Название»**, **«Редкость»**, **«Описание»**, **«Вес»** — редактирование предмета;
- **«Картинка»** — загрузка файла PNG/JPG/WEBP/GIF через модальное окно или прямая ссылка;
- **Анонс** — включает публичное оповещение о выпадении этого предмета;
- **«Начислить валюту»** — выбрать пользователя и выдать ему от 1 до 1 000 000 осколков;
- **«Удалить»** — убирает предмет из пула, но уже полученные копии остаются в инвентарях.

Загруженные картинки сохраняются в `assets/gacha`. Если переносите бота на другой сервер, скопируйте эту папку вместе с `data/store.json`.

### Гарантированные роли

За общее количество круток бот выдаёт три роли:

| Роль | Порог | Иконка |
|---|---:|---|
| **Лудик** | 50 круток | `assets/gacha/ludik.png` |
| **Гигача** | 80 круток | `assets/gacha/gigacha.png` |
| **Лудик король** | 150 круток | `assets/gacha/ludik-korol.png` |

- Считаются все крутки пользователя, а не только прогресс гарантии.
- Роль выдаётся один раз; прогресс виден в `/гача`.
- При получении новой роли предыдущая роль снимается — у пользователя остаётся только высшая.
- Если роли с таким названием нет, бот создаст её с соответствующим цветом. Если роль уже есть, бот использует её.
- Нужно право **Manage Roles**, и роль бота должна быть выше выдаваемых ролей.
- Если выдать роль не удалось, награда остаётся в статусе «ожидает выдачи» и бот попробует снова при следующем открытии `/гача` или крутке.

### Оповещение о «Ядре гармонии»

Когда пользователь получает предмет с включённым анонсом (у «Ядра гармонии» он включён по умолчанию), бот отправляет в канал, где использовали `/гача`, сообщение с упоминанием и золотой эмбед:

> **@Ник** получил из гачи **«Ядро гармонии»**

В эмбед добавляется иконка предмета. Пользователь получает упоминание, остальные роли и `@everyone` не пингуются.

## Хранение настроек

По умолчанию данные лежат в `data/store.json`:

- настройки сервера (название, лимиты, часовой пояс);
- созданные рейды;
- регистрации пользователей;
- активности, их расписания и описания;
- пул предметов гачи;
- балансы, инвентари, прогресс гарантии и полученные роли пользователей;
- события активностей и отметки о наградах;
- очередь сообщений на автоудаление;
- отметки об отправленных напоминаниях.

Специализации и иконки статические, в `data/store.json` они не настраиваются. Описание рейда хранится внутри конкретного рейда, но при создании следующего его нужно ввести снова.

Путь можно изменить переменной `DATA_FILE` в `.env`. Не публикуйте `.env` и `data/store.json`.
