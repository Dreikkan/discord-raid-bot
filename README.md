# Бот регистрации на рейд

Discord-бот на Python (`discord.py`) для еженедельных рейдов: публичный эмбед, пошаговая регистрация, автоматические счётчики мест, скамья запасных и напоминание за 15 минут до начала.

## Что реализовано

- Кнопка **«Зарегистрироваться»** под публичным эмбедом — страница 1.
- Пошаговая регистрация в личных (ephemeral) сообщениях:
  1. выбор роли: **Танк / Хил / ДД**;
  2. выбор специализации с иконкой;
  3. выбор статуса: **Присоединиться / Скамья запасных / Буду отсутствовать**.
- Если в основном составе выбранной роли нет свободных мест, «Присоединиться» автоматически записывает человека в **скамью запасных**.
- Публичный эмбед обновляется после каждой записи. В заголовках отображаются счётчики: `Танк (1/2)`, `Хил (0/3)`, `ДД (4/8)`.
- Иконка специализации выводится рядом с ником в эмбеде.
- Иконки ролей «Танк / ДД / Хил» и иконки специализаций загружаются из `assets` как кастомные emoji и подставляются автоматически.
- В комплекте уже настроены 11 специализаций: 1 танк, 1 хил и 9 ДД.
- Название, лимиты, иконки ролей, часовой пояс и список специализаций сохраняются между запусками.
- Описание **не сохраняется**: оно вводится заново при каждом `/рейд создать`, как и требовалось.
- За 15 минут до начала бот упоминает только **основной состав** и **скамью запасных**. Отсутствующие не упоминаются.
- Время выводится через Discord timestamps, поэтому каждый пользователь видит его в своём локальном часовом поясе.
- Данные регистраций сохраняются в JSON и не пропадают после перезапуска.
- Поддержка нескольких серверов (у каждого свои настройки и рейды).

## Быстрый запуск

Требуется Python 3.10+.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
python bot.py
```

Или на Windows просто запустите `run.bat` — он сам создаст окружение, установит зависимости и запустит бота.

В `.env` нужно указать:

```env
DISCORD_TOKEN=токен_бота
GUILD_ID=ID_сервера
```

`GUILD_ID` необязателен, но с ним слеш-команды появляются сразу. Без него команды синхронизируются глобально и могут появиться с задержкой.

### Создание приложения в Discord

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**.
2. Вкладка **Bot** → **Reset Token** → скопируйте токен в `.env`.
3. Privileged intents не нужны.
4. **OAuth2 → URL Generator**: scopes `bot` и `applications.commands`.
5. Права бота: **View Channels**, **Send Messages**, **Embed Links**, **Read Message History**, **Use External Emojis**, **Manage Expressions** (для автоматической загрузки иконок ролей и специализаций).
6. Пригласите бота на сервер по ссылке.
7. У пользователя, который настраивает бота, должно быть право **«Управлять сервером»** — команды настройки скрыты от остальных.

## Первичная настройка

Специализации уже предзагружены из каталога `assets/spec_icons/catalog.json`. Для нового файла данных ничего дополнительно импортировать не нужно.

### 1. Специализации и иконки

Текущий список: `/специализация список`.

При первом `/рейд создать` бот загрузит PNG-иконки из `assets/spec_icons` на сервер как кастомные emoji (`raid_spec_dryness`, `raid_spec_power` и т. д.) и сохранит их в настройках. Вручную это можно сделать командой:

```text
/специализация загрузить-иконки
```

Для загрузки нужно право бота **«Управлять выражениями»**. Если его нет, специализации и рейд создадутся, но без иконок — бот предупредит об этом.

Добавить специализацию вручную:

```text
/специализация добавить роль:Танк название:Страж иконка:🐻
```

Иконка — Unicode emoji (`🐻`) или кастомный emoji сервера в виде `<:название:ID>`. Получить тег уже загруженной иконки можно, отправив в чат `\:имя_emoji:`.

Удалить специализацию:

```text
/специализация удалить специализация:<начать вводить название>
```

Массовый импорт — прикрепите JSON-файл к команде:

```text
/специализация импорт файл:<вложение> заменить:true
```

Форматы JSON:

```json
[
  {"role": "tank", "name": "Страж", "emoji": "🐻"},
  {"role": "heal", "name": "Жрец", "emoji": "✨"},
  {"role": "dd", "name": "Маг", "emoji": "🔮"}
]
```

или с группировкой по ролям:

```json
{
  "tank": [{"name": "Страж", "emoji": "🐻"}],
  "heal": [{"name": "Жрец", "emoji": "✨"}],
  "dd": [{"name": "Маг", "emoji": "🔮"}]
}
```

Ограничение — **25 специализаций на одну роль** (ограничение меню Discord). Если в одной роли их больше, нужна пагинация — сообщите, добавлю.

### 2. Настройки эмбеда

```text
/эмбед название название:Еженедельный рейд
/эмбед лимиты танки:2 хилы:3 дд:8
/эмбед иконки танк:🛡️ хил:💚 дд:⚔️
/эмбед часовой_пояс часовой_пояс:Europe/Moscow
/эмбед загрузить-иконки
/эмбед показать
```

- Название, лимиты, иконки и часовой пояс используются в **новых** эмбедах. Уже созданные эмбеды не перезаписываются.
- Лимиты задаются для основного состава отдельно по ролям.
- Часовой пояс нужен только для ввода даты/времени администратором. Участники видят время локально.
- Поддерживаются IANA-пояса (`Europe/Moscow`) и смещения (`UTC+3`).
- Иконки ролей из `assets/role_icons` загружаются автоматически при первом `/рейд создать`, если у бота есть право **«Управлять выражениями»**. Команда `/эмбед загрузить-иконки` запускает загрузку вручную. Emoji получают имена `raid_tank`, `raid_dd`, `raid_heal`. Ручная команда `/эмбед иконки` отключает автоподстановку до повторной загрузки из файлов.

### 3. Создание рейда

Команду нужно вызывать в том канале, где должен появиться эмбед:

```text
/рейд создать описание:Сбор в Discord за 10 минут дата:26.10.2026 время:20:30
```

- Заголовок и лимиты берутся из сохранённых настроек.
- Описание вводится каждый раз заново.
- Дата: `ДД.ММ.ГГГГ` (также поддерживаются `YYYY-MM-DD` и `ДД/ММ/ГГГГ`).
- Время: `ЧЧ:ММ`.
- Бот публикует эмбед и кнопку «Зарегистрироваться».
- Напоминание уйдёт в этот же канал за 15 минут до начала, если бот в сети.

## Как проходит регистрация

1. Пользователь нажимает **«Зарегистрироваться»** под эмбедом.
2. Бот открывает личное сообщение с выбором роли.
3. После выбора роли открывается выбор специализации (только для этой роли).
4. После выбора специализации — выбор статуса.
5. Публичный эмбед сразу обновляется: счётчики, ники, иконки, скамья и отсутствующие.

Повторное нажатие кнопки позволяет изменить роль, специализацию или статус. Если основной состав роли заполнен, кнопка «Присоединиться» сохранит человека в скамье запасных и покажет предупреждение.

## Напоминание

Планировщик проверяет рейды каждые 20 секунд. В момент «за 15 минут» бот отправляет в канал рейда:

- упоминания всех из основного состава;
- упоминания всех из скамьи запасных;
- никого из «Буду отсутствовать».

Если бот был выключен в момент напоминания и включился до начала рейда, напоминание будет отправлено с задержкой. Если рейд уже начался — не отправляется. Бот должен быть запущен постоянно.

## Хранение настроек

По умолчанию данные лежат в `data/store.json`:

- настройки сервера (название, лимиты, иконки, часовой пояс, специализации);
- созданные рейды;
- регистрации пользователей;
- отметки об отправленных напоминаниях.

Описание рейда хранится внутри конкретного рейда, но не как настройка — при создании следующего рейда его нужно ввести снова.

Путь можно изменить переменной `DATA_FILE` в `.env`. Не публикуйте `.env` и `data/store.json` — в них служебные ID и токен.

## Команды

| Команда | Назначение |
|---|---|
| `/рейд создать` | Опубликовать новый рейд |
| `/эмбед название` | Сохранить заголовок |
| `/эмбед лимиты` | Сохранить количество мест |
| `/эмбед иконки` | Сохранить иконки ролей вручную |
| `/эмбед загрузить-иконки` | Загрузить иконки ролей из `assets` |
| `/эмбед часовой_пояс` | Сохранить часовой пояс ввода |
| `/эмбед показать` | Показать сохранённые настройки |
| `/специализация добавить` | Добавить/обновить специализацию |
| `/специализация загрузить-иконки` | Загрузить PNG-иконки специализаций из `assets` |
| `/специализация удалить` | Удалить специализацию |
| `/специализация список` | Показать список |
| `/специализация импорт` | Импортировать JSON |

Все команды требуют права **«Управлять сервером»**.

## Проверка логики

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты покрывают разбор времени и часовых поясов, лимиты и перенаправление в скамью, формирование эмбеда, импорт специализаций, сохранение данных и текст напоминания.

## Иконки

Роли и специализации используют PNG-иконки из `assets`:

- `assets/role_icons/tank.png`, `dd.png`, `heal.png`;
- `assets/spec_icons/<специализация>.png`;
- список специализаций и привязка к файлам — `assets/spec_icons/catalog.json`.

При первом создании рейда бот загружает отсутствующие иконки как emoji и сохраняет теги. Для этого нужно право **«Управлять выражениями»**. Повторная команда загрузки не создаёт дубликаты: emoji с зарезервированными именами переиспользуются.
